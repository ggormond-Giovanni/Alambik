# Plan d'implémentation — Alambic V1

> **Pour les agents :** SOUS-COMPÉTENCE REQUISE — utiliser `superpowers:subagent-driven-development` (recommandé) ou `superpowers:executing-plans` pour exécuter ce plan tâche par tâche. Les étapes sont des cases à cocher (`- [ ]`).

**But :** livrer une run complète et jouable au doigt d'Alambic sur Android — dix salles, deux alambics, un boss, quinze réactifs et dix fusions — installable sur l'appareil de test à chaque étape.

**Architecture :** Godot 4.7.1, GDScript, rendu 2D en `gl_compatibility` (mobile). Le combat lit des données, jamais des valeurs en dur : un `Tir` de base est transformé par les *mods* des réactifs possédés, et une fusion n'est qu'un réactif aux mods plus riches. Toute logique décidable sans scène (joystick, ciblage, agrégation des mods, tirage du draft, paires fusionnables) vit dans des classes `RefCounted` pures, testées en headless ; les nœuds ne font que les brancher à l'affichage.

**Pile technique :** Godot 4.7.1, GDScript, harnais de test maison en headless (pas de dépendance externe), SDK Android + `adb` déjà présents sur la machine.

## Contraintes globales

Ces règles s'appliquent à **toutes** les tâches.

- **Godot 4.7.1** exclusivement : `~/Téléchargements/Godot_v4.7.1-stable_linux.x86_64`.
- **Identifiants et commentaires en français sans accents** (contrainte GDScript). Les textes affichés au joueur gardent leurs accents : `"Flèche double"`, pas `"Fleche double"`.
- **Les commentaires disent pourquoi, pas quoi.**
- **Aucune valeur d'équilibrage en dur dans la logique.** Tout réglage vit dans `data/reglages.gd` ou dans les catalogues de données.
- **Le code de sortie ne suffit pas.** Après chaque tâche : lancer `./verifier.sh`, qui exécute les tests *et* greppe `SCRIPT ERROR`. Une erreur de compilation dans un script non sollicité laisse le harnais vert.
- **Aucun chiffre de performance ou d'équilibrage annoncé sans mesure.**
- **Rien qui vienne d'un jeu existant** : aucun nom de compétence, texte, icône, sprite ou son repris ; le mot « Archero » n'apparaît nulle part dans le dépôt.
- **Repli géométrique** : le jeu doit tourner de bout en bout sans un seul sprite.
- **GDScript** : `lerp`, `clamp`, `max`, `abs` renvoient du `Variant`. Utiliser `lerpf`, `clampf`, `maxf`, `maxi`, `absf` dans les `:=`.
- **Ne jamais modifier un tableau pendant qu'on l'itère** (ennemis morts, projectiles détruits) : itérer sur une copie ou à rebours.
- Commit après chaque tâche, message en français.

### Écart assumé par rapport à la spec

La spec annonçait `data/reactifs/*.tres`. On utilise à la place un **catalogue GDScript** (`data/catalogue_reactifs.gd`) qui construit les réactifs en mémoire. Raison : quinze ressources `.tres` s'éditent mal à la main, se relisent mal en diff et ne se testent pas ; un dictionnaire GDScript reste de la donnée pure, versionnable et vérifiable par assertion. L'intention de la spec — « un réactif n'est pas du code » — est respectée : aucun réactif ne contient de logique, seulement des mods déclaratifs.

- [ ] **Étape 1 : Écrire le harnais d'assertions**

`tests/verif.gd` :

```gdscript
class_name Verif
extends RefCounted

# Accumule les echecs au lieu de s'arreter au premier : une seule course
# doit dire tout ce qui est casse.

var total := 0
var echecs: Array[String] = []

func egal(obtenu, attendu, message: String) -> void:
	total += 1
	if obtenu != attendu:
		echecs.append("%s -- attendu %s, obtenu %s" % [message, attendu, obtenu])

func vrai(condition: bool, message: String) -> void:
	total += 1
	if not condition:
		echecs.append(message)

func presque(obtenu: float, attendu: float, message: String, marge := 0.001) -> void:
	total += 1
	if absf(obtenu - attendu) > marge:
		echecs.append("%s -- attendu ~%f, obtenu %f" % [message, attendu, obtenu])
```

`tests/lanceur.gd` :

```gdscript
extends SceneTree

const DOSSIER := "res://tests/"

func _initialize() -> void:
	var verif := Verif.new()
	var suites := 0
	for fichier in _fichiers_de_test():
		var script: GDScript = load(DOSSIER + fichier)
		var suite: RefCounted = script.new()
		suites += 1
		for methode in suite.get_method_list():
			if methode.name.begins_with("test_"):
				suite.call(methode.name, verif)
	print("Suites : %d   Assertions : %d   Echecs : %d" % [suites, verif.total, verif.echecs.size()])
	for echec in verif.echecs:
		print("  ECHEC  " + echec)
	quit(1 if not verif.echecs.is_empty() else 0)

func _fichiers_de_test() -> Array[String]:
	var trouves: Array[String] = []
	var dossier := DirAccess.open(DOSSIER)
	if dossier == null:
		push_error("Dossier de tests introuvable : " + DOSSIER)
		return trouves
	for fichier in dossier.get_files():
		if fichier.begins_with("test_") and fichier.ends_with(".gd"):
			trouves.append(fichier)
	trouves.sort()
	return trouves
```

- [ ] **Étape 3 : Écrire la logique**

`scripts/joystick_logique.gd` :

```gdscript
class_name JoystickLogique
extends RefCounted

const RAYON := 140.0
const ZONE_MORTE := 14.0

var _actif := false
var _origine := Vector2.ZERO
var _courant := Vector2.ZERO

func appuyer(position: Vector2) -> void:
	_actif = true
	_origine = position
	_courant = position

func deplacer(position: Vector2) -> void:
	if _actif:
		_courant = position

func relacher() -> void:
	_actif = false
	_origine = Vector2.ZERO
	_courant = Vector2.ZERO

func direction() -> Vector2:
	var ecart := _courant - _origine
	if not _actif or ecart.length() < ZONE_MORTE:
		return Vector2.ZERO
	return ecart.normalized()

func intensite() -> float:
	var ecart := _courant - _origine
	if not _actif or ecart.length() < ZONE_MORTE:
		return 0.0
	return minf(ecart.length() / RAYON, 1.0)
```

`ui/joystick.gd` :

```gdscript
extends Control

signal intention_changee(direction: Vector2, intensite: float)

var _logique := JoystickLogique.new()
var _doigt := -1

func _input(evenement: InputEvent) -> void:
	if evenement is InputEventScreenTouch:
		if evenement.pressed and _doigt == -1:
			_doigt = evenement.index
			_logique.appuyer(evenement.position)
		elif not evenement.pressed and evenement.index == _doigt:
			_doigt = -1
			_logique.relacher()
		else:
			return
	elif evenement is InputEventScreenDrag and evenement.index == _doigt:
		_logique.deplacer(evenement.position)
	else:
		return
	intention_changee.emit(_logique.direction(), _logique.intensite())
	queue_redraw()

func _draw() -> void:
	# Repli geometrique : le joystick se dessine, il n'a pas de sprite.
	if _doigt == -1:
		return
	var origine := _logique._origine
	draw_circle(origine, JoystickLogique.RAYON, Color(1, 1, 1, 0.10))
	draw_circle(origine + _logique.direction() * _logique.intensite() * JoystickLogique.RAYON,
		JoystickLogique.RAYON * 0.35, Color(1, 1, 1, 0.30))
```

```gdscript
	var pas := direction * tir.vitesse * delta
	position += pas
	_distance_parcourue += pas.length()
	if _distance_parcourue > tir.portee:
		queue_free()

func _sur_contact(corps: Node) -> void:
	if not corps.has_method("recevoir_degats"):
		return

	if _perforations_restantes > 0:
		_perforations_restantes -= 1
		return
	if _rebonds_restants > 0:
		_rebonds_restants -= 1
		direction = -direction
		return
	queue_free()
```

## Tâche 6 : Agrégation des mods — le moteur de la signature

**Fichiers :**
- Créer : `scripts/mods.gd`, `tests/test_mods.gd`

**Interfaces :**
- Produit : `Mods.appliquer(base: Tir, mods_liste: Array[Dictionary]) -> Tir`.
- Convention des clés, fixée ici une fois pour toutes :
  - suffixe `_add` → additionné (`nb_projectiles_add`, `rebonds_add`, `perforations_add`, `fragments_add`, `angle_eventail_add`)
  - suffixe `_mult` → multiplié (`degats_mult`, `cadence_mult`, `vitesse_mult`, `portee_mult`)

`scripts/mods.gd` :

```gdscript
class_name Mods
extends RefCounted

# Un reactif ne contient pas de logique : il decrit ce qu'il change.
# Les additions et les multiplications commutent, donc l'ordre d'acquisition
# des reactifs n'influe jamais sur le resultat.

const CHAMPS_ADD := {
	"nb_projectiles_add": "nb_projectiles",
	"rebonds_add": "rebonds",
	"perforations_add": "perforations",
	"fragments_add": "fragments",
	"angle_eventail_add": "angle_eventail",
}

const CHAMPS_MULT := {
	"degats_mult": "degats",
	"cadence_mult": "cadence",
	"vitesse_mult": "vitesse",
	"portee_mult": "portee",
}

static func appliquer(base: Tir, mods_liste: Array) -> Tir:
	var t := Tir.new()
	t.degats = base.degats
	t.vitesse = base.vitesse
	t.portee = base.portee
	t.cadence = base.cadence
	t.nb_projectiles = base.nb_projectiles
	t.angle_eventail = base.angle_eventail
	t.rebonds = base.rebonds
	t.perforations = base.perforations
	t.fragments = base.fragments
	t.effets = base.effets.duplicate()
	t.drapeaux = base.drapeaux.duplicate()

	for mod in mods_liste:
		for cle in CHAMPS_ADD:
			if mod.has(cle):
				t.set(CHAMPS_ADD[cle], t.get(CHAMPS_ADD[cle]) + mod[cle])
		for cle in CHAMPS_MULT:
			if mod.has(cle):
				t.set(CHAMPS_MULT[cle], t.get(CHAMPS_MULT[cle]) * mod[cle])
		for liste in ["effets", "drapeaux"]:
			if mod.has(liste):
				for valeur in mod[liste]:
					if not valeur in t.get(liste):
						t.get(liste).append(valeur)
	return t
```

```gdscript
extends CharacterBody2D

signal mort(qui: Node)

var pv := 0.0
var _cible: Node2D
var _recharge := 0.0
var _braise := 0.0
var _givre := 0.0
var _acide := 0.0

func configurer(donnees_: Dictionary) -> void:
	donnees = donnees_
	pv = donnees["pv"]

func _ready() -> void:
	add_to_group("ennemis")
	_cible = get_tree().get_first_node_in_group("heros")
	($CollisionShape2D.shape as CircleShape2D).radius = donnees["rayon"]

func _physics_process(delta: float) -> void:
	_appliquer_effets(delta)
	_recharge = maxf(0.0, _recharge - delta)
	if _cible == null:
		return
	var distance := global_position.distance_to(_cible.global_position)
	var decision := Cerveaux.rampant(distance, donnees["portee"])
	if decision == "avancer":
		var ralenti := Reglages.GIVRE_RALENTISSEMENT if _givre > 0.0 else 1.0
		velocity = global_position.direction_to(_cible.global_position) * donnees["vitesse"] * ralenti
		move_and_slide()
	elif _recharge <= 0.0:
		_recharge = 1.0
		_cible.recevoir_degats(donnees["degats"])

func recevoir_degats(montant: float, effets: Array[String] = []) -> void:
	var facteur := Reglages.ACIDE_VULNERABILITE if _acide > 0.0 else 1.0
	pv -= montant * facteur
	for effet in effets:
		match effet:
			"braise": _braise = Reglages.BRAISE_DUREE
			"givre": _givre = Reglages.GIVRE_DUREE
			"acide": _acide = Reglages.ACIDE_DUREE
	if pv <= 0.0:
		mort.emit(self)
		queue_free()

func _appliquer_effets(delta: float) -> void:
	if _braise > 0.0:
		_braise -= delta
		pv -= Reglages.BRAISE_DEGATS_PAR_SECONDE * delta
		if pv <= 0.0:
			mort.emit(self)
			queue_free()
			return
	_givre = maxf(0.0, _givre - delta)
	_acide = maxf(0.0, _acide - delta)

func _draw() -> void:
	draw_circle(Vector2.ZERO, donnees["rayon"], donnees["couleur"])
```

```gdscript
extends Node2D

signal terminee

const PROJECTILE := preload("res://scenes/projectile.tscn")
const ENNEMI := preload("res://scenes/ennemi.tscn")

@onready var _heros: CharacterBody2D = $Heros

var _vagues: Array = []
var _vague_courante := -1

func _ready() -> void:
	$CanvasLayer/Joystick.intention_changee.connect(_sur_intention)
	_heros.tir_demande.connect(_sur_tir)

func demarrer(numero: int) -> void:
	_vagues = Vagues.pour_salle(numero)
	_vague_courante = -1
	_vague_suivante()

func _vague_suivante() -> void:
	_vague_courante += 1
	if _vague_courante >= _vagues.size():
		terminee.emit()
		return
	for id in _vagues[_vague_courante]:
		var e := ENNEMI.instantiate()
		e.configurer(CatalogueEnnemis.TOUS[id])
		e.global_position = _position_d_apparition()
		e.mort.connect(_sur_mort_ennemi)
		add_child(e)

func _sur_mort_ennemi(_qui: Node) -> void:
	# Le noeud mort est encore dans l'arbre a cet instant : on attend une frame
	# avant de compter, sinon la vague ne se termine jamais.
	await get_tree().process_frame
	if get_tree().get_nodes_in_group("ennemis").is_empty():
		_vague_suivante()

func _position_d_apparition() -> Vector2:
	var marge := 120.0
	var largeur := float(ProjectSettings.get_setting("display/window/size/viewport_width"))
	var x := Jeu.rng.randf_range(marge, largeur - marge)
	return Vector2(x, marge)

func _sur_intention(direction: Vector2, intensite: float) -> void:
	_heros.definir_intention(direction, intensite)

func _sur_tir(tir_courant: Tir, origine: Vector2, direction: Vector2) -> void:
	for angle in tir_courant.angles():
		var p := PROJECTILE.instantiate()
		p.tir = tir_courant
		p.direction = direction.rotated(angle)
		p.global_position = origine
		add_child(p)
```

```gdscript
class_name AlambicLogique
extends RefCounted

static func paires_possibles(inventaire: Array) -> Array[Array]:
	var trouvees: Array[Array] = []
	var vues: Array[String] = []
	for i in inventaire.size():
		for j in range(i + 1, inventaire.size()):
			var a: String = inventaire[i]
			var b: String = inventaire[j]
			var essence := Recettes.essence_pour(a, b)
			if essence == "":
				continue
			var c := Recettes.cle(a, b)
			if c in vues:
				continue
			vues.append(c)
			trouvees.append([a, b, essence])
	return trouvees

static func peut_fusionner(inventaire: Array, a: String, b: String) -> bool:
	if a == b or not a in inventaire or not b in inventaire:
		return false
	return Recettes.essence_pour(a, b) != ""
```

Une essence ne peut jamais être composant : elle n'apparaît dans aucune clé de `Recettes.TABLE`, donc `essence_pour` renvoie `""` — la règle de la spec est garantie par la structure de données, pas par une vérification qu'on pourrait oublier.

```gdscript
		bouton.disabled = not id in fusionnables and not id in _selection
		bouton.button_pressed = id in _selection
		bouton.pressed.connect(_sur_choix.bind(id))
		$Grille.add_child(bouton)
	$Fusionner.disabled = _selection.size() != 2 \
		or not AlambicLogique.peut_fusionner(Jeu.inventaire, _selection[0], _selection[1])
	$Passer.text = "Quitter sans fusionner"

func _ids_fusionnables() -> Array[String]:
	var ids: Array[String] = []
	for paire in AlambicLogique.paires_possibles(Jeu.inventaire):
		# Un premier reactif deja choisi restreint les partenaires acceptables.
		if _selection.size() == 1 and not _selection[0] in [paire[0], paire[1]]:
			continue
		for id in [paire[0], paire[1]]:
			if not id in ids:
				ids.append(id)
	return ids

func _sur_choix(id: String) -> void:
	if id in _selection:
		_selection.erase(id)
	elif _selection.size() < 2:
		_selection.append(id)
	_construire()

func _sur_fusionner() -> void:
	var essence := Recettes.essence_pour(_selection[0], _selection[1])
	Jeu.retirer_reactifs(_selection)
	Jeu.ajouter_reactif(essence)
	termine.emit()

func _sur_passer() -> void:
	# La spec est explicite : garder ses reactifs est un choix legitime.
	termine.emit()

func _reactif(id: String) -> Reactif:
	var r := CatalogueReactifs.par_id(id)
	return r if r != null else CatalogueEssences.par_id(id)
```

```gdscript
extends Node

# Le bot passe par definir_intention(), la meme porte que le joystick. Piloter
# des entrees simulees a deja fait rapporter des succes faux sur un autre projet :
# Input.action_press() appele chaque frame re-declenche is_action_just_pressed().

var _heros: CharacterBody2D
var _minuterie := 0.0

func _process(delta: float) -> void:
	if _heros == null or not is_instance_valid(_heros):
		_heros = get_tree().get_first_node_in_group("heros")
		return
	_minuterie -= delta
	var ennemis := get_tree().get_nodes_in_group("ennemis")
	if ennemis.is_empty():
		_heros.definir_intention(Vector2.ZERO)
		return
	# Alternance grossiere : on s'ecarte, on s'arrete pour tirer. Le but n'est
	# pas de bien jouer, c'est de traverser une run sans intervention.
	if _minuterie <= 0.0:
		_minuterie = 0.8
		var menace: Node2D = ennemis[0]
		var fuite := menace.global_position.direction_to(_heros.global_position)
		_heros.definir_intention(fuite if _heros.stats.pv < _heros.stats.pv_max * 0.5 else Vector2.ZERO)
```

`sondes/vingt_runs.sh` :

```sh
#!/bin/sh
# Vingt runs completes sans intervention. Une run qui n'atteint jamais la salle
# 10 n'est pas forcement un bug d'equilibrage : c'est peut-etre un blocage.
GODOT="$HOME/Téléchargements/Godot_v4.7.1-stable_linux.x86_64"
ECHECS=0

for GRAINE in $(seq 1 20); do
    SORTIE=$("$GODOT" --headless --path . --audio-driver Dummy --fixed-fps 60 \
        --quit-after 18000 -- --auto --graine="$GRAINE" 2>&1)
    if echo "$SORTIE" | grep -q "SCRIPT ERROR"; then
        echo "graine $GRAINE : SCRIPT ERROR"
        ECHECS=$((ECHECS + 1))
    fi
    echo "$SORTIE" | grep -E "run terminee|salle atteinte" | sed "s/^/graine $GRAINE : /"
done

echo "Runs en echec : $ECHECS / 20"
exit "$ECHECS"
```

`--quit-after 18000` correspond à 300 secondes de jeu à 60 images par seconde — assez pour une run complète, sans que la sonde ne s'arrête à mi-parcours en annonçant un succès qui ne prouve rien.
